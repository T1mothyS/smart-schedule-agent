## 设计决定

- 保留设置弹层入口；桌面居中，最大宽度 980px，左侧分类导航。手机为全屏纵向分区，关闭栏固定，内容独立滚动，底部保留安全区间距。
- 桌面设置行采用两列 Grid，手机改为单列。控件统一 `min-width: 0`，输入/选择器自适应，按钮组可换行，关闭按钮 44×44px，Switch 保持 36px 宽。
- 所有分类始终挂载，只滚动到对应位置；切换分类不会丢失未保存输入或一次性令牌。关闭设置仍结束本次编辑。
- 保留原有请求地址、方法、字段、账号身份头、通知保存后回读确认、令牌轮换/撤销确认、QQ 删除确认和备份替换确认。
- 补充初始读取失败/重试、模型保存错误反馈和忙碌时禁用；AI 编辑器等配置读取完成才打开，取消或保存后清空 Key 草稿。按钮明确使用原生 button，Switch 提供可访问的选中状态。
- 当前 TDesign Input 不直接支持原生 id，通过公开的 inputElement 接口关联标签；设置 Dialog 的 Flex 样式覆盖组件动画写入的 display:block；模型菜单限制宽度并允许长选项换行。这些兼容点均经实际浏览器验证。
