## 范围与语义

默认 `CALDAV_BRIDGE_SCOPE=all`，包含绑定账号的全部日历（含网页隐藏日历）的未完成已排期 event/todo，以及启用周期事务当前 pending/expired 周期。`selected` 仅作为明确配置的旧试点例外。无隐含日期窗口，过去/逾期但未完成的 event、todo 仍纳入；完成历史、未排期、AI 未确认草稿不纳入。源数据库不被桥接修改，亦不创建周期、投递或邮件。

- event 保留既有 UID；todo 在手机投影为 VEVENT，标题加“待办：”，源类型不变。完成/重新打开分别撤回/恢复同一投影。
- 周期来自权威 reminder store 的纯读当前周期（与现有逻辑同为最近创建周期），使用 cycle ID 生成独立全天事件，标题加“周期事务：”；不生成 RRULE，不遍历历史周期，源日程表 reminder-cycle 副本排除去重。启用任务缺少当前周期视为来源不完整，停止批次，交由正常周期业务初始化。
- 普通定时事件缺结束时间只在目标补 60 分钟，不改源库。单日全天输出 DATE 与次日排他结束；多日/歧义全天仍需用户修正源语义。
- 无偏移时间按明确配置解释；支持 Asia/Shanghai、Asia/Hong_Kong、UTC，2000 年起；输出 UTC。每日/每周输出无终止 RRULE；monthly、复杂重复/单次例外保持待处理，不猜测。
- description 与 notes 合并，保留地点、中文、Emoji、换行与 UTF-8 折行。不外发内部风险/完成等业务字段。时间、事件语义遵循 [RFC 5545](https://www.rfc-editor.org/rfc/rfc5545.html)。
- 手机提醒默认关闭；开启后仅投影非全天、单个 0–10080 分钟数字提醒。其他提醒不输出，并返回 ALARMS_DISABLED 提示，不阻断内容显示。周期事务不推导午夜提醒，邮件提醒不等于手机提醒。
- 内容转换错误按 sourceId 隔离：旧投影 `held` 保留，新问题项不写，其余有效项可执行。`complete=false` 明确表示不是全量成功；提醒提示本身不影响“内容全量”，但不证明提醒可用。
- 源读取失败、归属异常、缺少权威周期、容量超过 500、远端冲突或状态损坏阻断批次；失败不能当空源删除。容量同时检查候选数与目标/账本并集，不截断。

## 配置与网站接口

实际绑定、URL 与凭据只放忽略配置；配置变更重启生效，UI 不接收或返回上游密码/URL。

| 配置 | 默认与含义 |
|---|---|
| CALDAV_BRIDGE_ENABLED / WRITE_ENABLED | false；分别启用桥接和允许写入 |
| CALDAV_BRIDGE_SCOPE | all；默认绑定账号全部日历；仅旧试点显式设置 selected |
| CALDAV_BRIDGE_USER_ID | 唯一账号，所有接口检查 JWT 与之相符 |
| CALDAV_BRIDGE_CALENDAR_IDS | selected 时 1–10 个明确日历 ID；迁移时保留原列表用于校验 v1 绑定 |
| CALDAV_BRIDGE_COLLECTION_URL | 已存在的 HTTPS 集合，末尾 /，不含账号/查询/fragment |
| CALDAV_BRIDGE_USERNAME / PASSWORD | 独立 writer；手机使用独立 reader |
| CALDAV_BRIDGE_TIMEZONE | Asia/Shanghai |
| CALDAV_BRIDGE_INCLUDE_COMPLETED | false；本次全量保持 false |
| CALDAV_BRIDGE_ALARMS_ENABLED | false；合成真机提醒验收后单独放行 |
| CALDAV_BRIDGE_AUTOMATION_ALLOWED | false；仅允许网站开启自动化，本身不会开启 |

自动化还要求既有 BACKGROUND_JOBS_ENABLED=true。不得为了 CalDAV 随意开启原本关闭的邮件/备份 worker；先核对唯一 worker 的既有运行配置。

设置页“荣耀日历同步”展示范围、状态、最近写入、分类数量、排除原因、逐项操作与待处理项；提供预览、确认同步、自动化暂停/启用。源 ID 用于定位项目，状态不声称手机已刷新。日历范围与日程分类不混用；本期不是全站日历管理重构。

- `GET /api/integrations/caldav/status`：非秘密控制状态、scopeVersion、写入/自动化许可、最近成功与错误、重试时间、上次结果摘要。
- `POST .../preview {}`：纯读，返回 planToken、scopeVersion、operations、counts、exclusions、issues、complete、migrationRequired、requiresDeleteConfirmation；不写账本，不写 CalDAV。
- `POST .../sync {planToken}`：重新预览比较令牌；用户确认的计划才执行。已确认令牌包含全部操作和迁移，不接受任意新增字段。成功返回 applied，但 complete 单独判断。
- `POST .../automation {enabled, scopeVersion?, phoneVerified?}`：启停。开启要求服务器许可、写入许可、此范围已有 complete 的成功同步，且本范围已有手机核心验证声明（首次 phoneVerified=true）。UI 提醒验证创建、修改、删除、完成撤回和只读行为；声明由用户负责，不伪装成自动真机检测。
- 范围版本包含目标身份、范围策略、时间/提醒/完成策略和投影版本，不因 all 模式新增日历而改变。修改策略后必须重新同步与确认。手机提醒开关仍在服务器端单独授权。
- 同步/预览/自动化控制共用互斥；维护/恢复期间拒绝运行。无登录 401、其他账号/写入关闭 403、配置关闭 404、无效输入 400、冲突/闸门 409、上游失败 502、内部失败 503。所有错误只返回固定代码，限流 30 次/分钟。

## 账本迁移、自动化和恢复

v2 `DATA_DIR/caldav-bridge/state.json` 绑定账号与集合身份，和范围版本分开。普通事件资源键保持不变；跨日历移动仍按既有键规则表现为旧撤回/新创建。

v1 迁移需保留原 CALENDAR_IDS，以旧账号/日历/集合摘要核验。预览读取每个自有资源并校验 ETag/内容；缺失或冲突阻断。确认 sync 后先将旧账本与资源原文保存到本地 `migration-*.json`（权限600），再原子转换 v2；备份可能含日程正文，仅存运行目录，不进日志/Git。运维还须在扩大范围前做独立目标备份。禁止删账本重建。

- 每 5 分钟检查一次，启动后从首次调度开始；单进程共享服务与互斥、账本文件排他锁。没有另起 Python 读取主应用库。
- 自动化默认暂停，首次完整同步与手机声明后才持久启用。每轮从完整源快照生成差异，先写后删，只操作账本自有资源，绝不清空整个集合。
- 每次远端变更前检查源签名；PUT 前持久化 pending，响应不明确时按内容核对恢复。部分成功不能网络原子回滚，重试重新预览。
- 网络/临时上游故障按 5/10/20/30 分钟退避；成功复位。认证、冲突、账本异常等暂停；单项目转换异常保留旧投影并显示未完成，已启用范围仍可继续同步其他有效项目。
- 删除至少10条且占账本20%，或清空至少5条的全部账本，暂停自动执行，要求手动预览确认；普通单条完成/删除自动传播。
- 自动化开启后目标通常在下一次调度更新；串行请求每次最多15秒，不承诺手机实时或固定刷新延迟。

系统加密快照包含账本及非秘密控制文件，不包含上游凭据或 Radicale 数据。自动/手动系统备份等待在途桥接结束再捕获，不撤销自动化设置；用户恢复（绑定账号）和全站恢复则先等待并暂停，清除范围/手机声明，恢复后必须重新预览与确认。全站恢复将桥接目录纳入原有恢复事务日志/回滚；旧快照没有桥接字段时保留现有账本并暂停，不能清空所有权。用户导出不携带机器级桥接状态。

Radicale 集合须单独备份；联合恢复后先比对远端，冲突停止，不自动覆盖。崩溃残留锁只在确认原进程已停止并保留现场后人工处理。回滚前先关闭自动化与写入，保留原账本/资源；v2 账本不能直接由旧版桥接使用，旧代码回滚须保持桥接关闭。

## 验证和部署门槛

本地测试包含投影与隔离、v1迁移备份、错误保留、批量撤回、自动化授权/退避、恢复排他、快照状态与账号边界。真实 Radicale 合成链路覆盖9个来源（含todo、另一日历与周期），创建/更新/删除、重复执行、reader拒写、源库字节不变，原有9个seed保留。浏览器使用合成接口，覆盖四个规定视口、浅暗主题、错误、长ID、确认与自动化控制。

部署顺序：本地门禁→另行授权生产部署→保持自动化/提醒关闭→备份并只读统计实际来源→默认 all（保留旧日历 ID 供迁移核验）→预览审阅与确认迁移/全量→手机核心验收→开放自动化许可并由网站确认启用→至少24小时网络切换/锁屏/断网和服务重启观察。正式自动化启用时单独配置并验收 Radicale 开机启动。锁屏实际提醒用未来合成事件单独验证后放行。

本地通过不代表生产部署、全量真实数据或真机验收通过。前次25→1条的回执只证明当时选定日历试点；不得据此宣称本次全量已执行。
