V5 仍然是单文件前端：没有后端、没有数据库、没有上传。成本优先使用 ccusage JSON 返回值；仅在缺失时使用内置价格表兜底。遇到新模型且 ccusage 未提供成本、内置表也无法识别时，明确显示 N/A，不用 $0 或部分成本冒充完整成本。模型排序按 GPT 版本号自动降序，同版本再按 Astra → Sol → Terra → Luna 排序，因此未来多数新版本无需修改 HTML。Cache Read Rate = Cache Read / (Input + Cache Write + Cache Read)。
